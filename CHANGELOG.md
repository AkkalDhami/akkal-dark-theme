# Changelog

Notable updates to the Akkal Dark Theme collection are listed here.

## [1.0.8] - 2026-11-13

### Added

- Added **Ayu Dark**, bringing another carefully adapted dark palette to the collection.
- Added Ayu Dark theme keywords to improve discoverability.

## [1.0.7] - 2026-11-05

### Added

- Added **Vesper Dark**, a deep black theme with warm accents.
- Added theme keywords to improve discoverability.

### Improved

- Refined Akkal Dark's active line number color.
- Added a hover color for the extension button.

## [1.0.6] - 2026-08-09

### Added

- Added **Akkal Midnight**, a softer, more muted alternative to Akkal Dark.
- Made Akkal Midnight available as a theme option.

## [1.0.5] - 2026-07-30

### Improved

- Refined Markdown heading colors for improved readability and visual hierarchy.
- Updated bright terminal ANSI colors for better contrast and consistency.
- Adjusted the selection highlight background to make highlighted matches more visible.
- Made additional color refinements for a more consistent editing experience.

## [1.0.4] - 2026-07-27

### Changed

- Refined comment and Markdown heading colors.
- Improved the color of bold Markdown text.
- Made additional color refinements for a more consistent appearance.

## [1.0.3] - 2026-07-26

### Improved

- Refined syntax highlighting across multiple languages.
- Added dedicated colors for numbers, booleans, and language constants.
- Improved Java highlighting for modifiers and primitive types.
- Improved overall color consistency and readability.

## [1.0.2] - 2026-07-25

### Added

- Added dedicated syntax highlighting for numeric literals and boolean values.
- Added dedicated syntax highlighting for constants such as `null`, `undefined`, `None`, and `nil`.

### Improved

- Improved syntax highlighting consistency across multiple languages.

## [1.0.1] - 2026-07-25

### Added

- Added screenshots to the README.
- Improved the extension's visual presentation.

## [1.0.0] - 2026-07-24

### Added

- Initial release of Akkal Dark Theme.
- Added a dark palette inspired by the One Dark Pro aesthetic.
- Added custom syntax highlighting, semantic highlighting, and editor, workbench, and terminal colors.

# Changelog

All notable changes to **Akkal Dark Theme** will be documented here.

## [1.0.2] - 2026-07-25

### Added

- Added dedicated syntax highlighting for numeric literals.
- Added dedicated syntax highlighting for boolean values (`true`/`false`).
- Added dedicated syntax highlighting for language constants such as `null`, `undefined`, `None`, and `nil`.

### Improved

- Enhanced syntax highlighting consistency across multiple programming languages.

## [1.0.0] - 2026-07-24

### Added

- Initial release of Akkal Dark Theme
- Dark color palette inspired by the classic One Dark Pro aesthetic
- Custom syntax highlighting for popular languages
- Semantic highlighting support
- Custom editor, workbench, and terminal colors
